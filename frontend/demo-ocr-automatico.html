🤖 OCR Automático para Comprovantes PIX

Extração automática de dados usando Firebase Extensions

🔄 Fluxo do Processo

1
Upload
Usuário faz upload do comprovante PIX (JPG/PNG)
2
Storage
Arquivo salvo em /comprovantes/ no Firebase Storage
3
OCR
Extensão Firebase extrai texto automaticamente
4
Firestore
Texto salvo em /textos_comprovantes/
5
Escuta
Frontend escuta mudanças via onSnapshot
6
Extração
Algoritmo extrai valor, data e descrição

🧠 Algoritmos de Extração

Extração de Valor:

// Regex para capturar valores monetários const regexValor = /(?:R\$\s*)?(\d{1,3}(?:\.\d{3})*(?:,\d{2}))/g; // Exemplos que funciona: // R$ 1.250,00 → 1250.00 // 1.500,50 → 1500.50 // R$\s*2.000,00 → 2000.00

Extração de Data:

// Regex para capturar datas em vários formatos const regexData = /(\d{1,2})[\/\-](\d{1,2})[\/\-](\d{4})|(\d{4})[\/\-](\d{1,2})[\/\-](\d{1,2})/g; // Exemplos que funciona: // 15/11/2024 → 2024-11-15 // 15-11-2024 → 2024-11-15 // 2024-11-15 → 2024-11-15

Extração de Nome:

// Regex para capturar nome do pagador const regexNome = /(?:de|para|pagador|remetente|origem)[:\s]+([A-ZÁÊÔÓÍ][A-Za-záêôóíç\s]+)(?:\n|$|CPF|\d)/i; // Exemplos que funciona: // "De: JOÃO SILVA" → "PIX recebido de JOÃO SILVA" // "Pagador: MARIA SANTOS" → "PIX recebido de MARIA SANTOS"

⚙️ Implementação Técnica

🔥 Configuração Firebase Extension:

  • Path: comprovantes/{imageFileName}
  • Collection: textos_comprovantes/{documentId}
  • Languages: pt (Português)
  • Output: text + confidence scores

👂 Escuta Real-time:

  • onSnapshot: Escuta mudanças na coleção
  • Query: Filtra por originalImagePath
  • Timeout: 30 segundos para evitar escuta infinita
  • Auto-fill: Preenche campos automaticamente
