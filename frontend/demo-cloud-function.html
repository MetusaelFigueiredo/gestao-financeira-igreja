🤖 Cloud Function para Processamento de PDFs

Extração automática de dados de comprovantes PIX usando Node.js

🏗️ Arquitetura da Solução

1
📤 Upload PDF
Usuario faz upload do comprovante via UploadComprovante
2
🔥 Storage Trigger
Cloud Function detecta novo arquivo em comprovantes/
3
📥 Download PDF
Function baixa o arquivo do Firebase Storage
4
📝 Extrair Texto
pdf-parse converte PDF em texto puro
5
🔍 Regex Search
Expressões regulares encontram valor, data e nome
6
💾 Update Firestore
Dados extraídos são salvos no documento

🔍 Expressões Regulares Implementadas

💰 Extração de Valor
/R\$\s*(\d{1,3}(?:\.\d{3})*,\d{2})/gi
Encontra:
• R$ 1.234,56
• R$1.234,56
• R$ 500,00
📅 Extração de Data
/(\d{1,2}\/\d{1,2}\/\d{2,4})/g
Encontra:
• 15/11/2024
• 01/12/24
• 25/12/2024
👤 Extração de Nome
/(?:Nome|Para):\s*([A-Z\s]{3,50})/gi
Encontra:
• Nome: MARIA SILVA
• Para: JOÃO SANTOS
• Recebedor: ANA COSTA

⚙️ Stack Tecnológica

🔥
Firebase Functions
Plataforma serverless para executar código Node.js em resposta a eventos
📄
pdf-parse
Biblioteca Node.js para extrair texto de arquivos PDF
🔍
RegExp
Expressões regulares JavaScript para encontrar padrões no texto
🗃️
Firestore
Banco NoSQL para armazenar dados extraídos dos PDFs

💻 Código Principal da Function

exports.processarComprovantePIX = functions.storage.object().onFinalize(async (object) => { const filePath = object.name; // 1. Verificar se é PDF na pasta comprovantes/ if (!filePath.startsWith('comprovantes/') || !filePath.endsWith('.pdf')) { return null; } // 2. Baixar e processar PDF const bucket = admin.storage().bucket(object.bucket); const [fileBuffer] = await bucket.file(filePath).download(); const pdfData = await pdfParse(fileBuffer); // 3. Extrair dados com Regex const dadosExtraidos = extrairDadosPIX(pdfData.text); // 4. Atualizar Firestore const db = admin.firestore(); await db.collection('entradas') .where('comprovanteUrl', '>=', comprovanteUrl) .get() .then(snapshot => { snapshot.forEach(doc => { doc.ref.update({ valorExtraido: dadosExtraidos.valor, dataExtraida: dadosExtraidos.data, nomeExtraido: dadosExtraidos.nome, processadoPorCloudFunction: true }); }); }); });

🔄 Antes vs Depois

❌ Antes (Extensões Gemini)
  • Dependência de extensões externas
  • Configuração complexa
  • onSnapshot listeners
  • Timeout de 2 minutos
  • Processamento inconsistente
  • Difícil de debugar
  • Limitações de formato
✅ Depois (Cloud Function)
  • Código próprio e controlável
  • Configuração simples
  • Trigger automático do Storage
  • Processamento instantâneo
  • Regex personalizáveis
  • Logs detalhados
  • Foca apenas em PDFs
