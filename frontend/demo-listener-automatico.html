👂 aguardarProcessamentoGemini() - Nova
const aguardarProcessamentoGemini = async (docRef) => {
  return new Promise((resolve) => {
    const unsubscribe = onSnapshot(docRef, (snap) => {
      const dados = snap.data();
      
      if (dados && dados.resultadoOcr) {
        // Parse JSON do Gemini
        const resultado = JSON.parse(dados.resultadoOcr);
        
        // Atualizar campos
        updateDoc(docRef, {
          valor: resultado.valor,
          data: convertData(resultado.data),
          descricao: `PIX de ${resultado.nome}`
        });
        
        unsubscribe(); // Parar escuta
        resolve();
      }
    });
  });
};

🎯 Ponto Chave da Implementação

O listener onSnapshot() monitora especificamente o campo resultadoOcr. Assim que o Gemini adiciona este campo ao documento, o código:

  • Faz parse do JSON retornado pelo Gemini
  • Atualiza os campos principais (valor, data, descrição)
  • Recalcula o rateio com o novo valor
  • Marca como processado e cancela o listener
