✨ Gemini AI para Comprovantes PIX

Extração inteligente de dados com IA Multimodal

⚖️ Evolução da Solução

🔴 Solução Anterior (OCR)
  • Apenas imagens JPG/PNG
  • Texto bruto não estruturado
  • Regex complexas para extração
  • Baixa precisão com qualidade ruim
  • Não processa PDFs
  • Falhas com layouts diferentes
🟢 Solução Atual (Gemini AI)
  • Suporte a JPG, PNG e PDF
  • Retorna JSON estruturado
  • IA entende contexto
  • Alta precisão mesmo com ruído
  • Processa documentos complexos
  • Adaptável a qualquer layout

🚀 Recursos do Gemini AI

🧠
Inteligência Contextual
Entende o contexto do documento e extrai informações relevantes mesmo com layouts diferentes
📄
Suporte Multi-formato
Processa imagens (JPG, PNG) e documentos PDF com a mesma eficiência
🎯
JSON Estruturado
Retorna dados organizados em formato JSON, eliminando parsing complexo
⚡
Alta Performance
Processamento rápido com modelo Gemini-1.5-Flash otimizado para velocidade

⚙️ Configuração da Extensão

🔧 Configurações Recomendadas:

  • Model: gemini-1.5-flash (velocidade)
  • Temperature: 0.1 (precisão)
  • Max Tokens: 256
  • Output Format: application/json

📝 Prompt Template:

Analise este comprovante PIX e extraia as seguintes informações em formato JSON: { "valor": [valor numérico da transação], "data": "[data no formato DD/MM/YYYY]", "nome": "[nome completo do pagador/remetente]" } Se alguma informação não estiver disponível, use null para o campo. Retorne apenas o JSON, sem texto adicional.

🔄 Fluxo de Integração

1
Upload
Usuário faz upload do comprovante (JPG/PNG/PDF) no FormEntrada
2
Storage
Arquivo armazenado na pasta /comprovantes/ do Firebase Storage
3
Trigger
Extensão Gemini detecta novo arquivo e inicia processamento
4
Análise AI
Gemini AI analisa o documento e extrai dados relevantes
5
JSON Response
Resposta estruturada salva em /processamento_gemini/
6
Real-time Update
Frontend escuta via onSnapshot e preenche campos automaticamente
